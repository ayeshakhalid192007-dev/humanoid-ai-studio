# Modern AI-Themed Homepage for Physical AI Robotics

## Overview

This repository contains a modern, premium, AI-themed homepage for the "Master Physical AI & Humanoid Robotics" learning platform built with Next.js, React, Tailwind CSS, and Framer Motion.

## Features

- **Dark-mode-first, futuristic design** with blue-purple-indigo gradient accents
- **Responsive layout** supporting desktop, tablet, and mobile devices
- **Smooth animations** using Framer Motion
- **Modular, reusable components** for maintainability
- **AI/robotics aesthetic** with glassmorphism and glow effects

## Homepage Sections

1. **Hero Section**
   - Full-screen animated gradient background with subtle radial glow
   - Main heading: "Master Physical AI & Humanoid Robotics"
   - Subtitle describing the AI-powered learning platform
   - CTA buttons: "Get Started" and "Explore Features" with hover effects

2. **About Section**
   - Centered glassmorphism container
   - Explanation of the platform's AI-powered tutoring and simulation capabilities

3. **Core Learning Pillars** (6 feature cards)
   - AI Tutor
   - Interactive Simulations
   - Structured Curriculum
   - Personalized Chapters
   - Urdu Translation
   - Intelligent RAG Chatbot

4. **Features Overview**
   - 11 technology features including ROS 2, NVIDIA Isaac, Reinforcement Learning, Vision-Language Systems, and more

5. **Footer**
   - Project name with gradient text effect
   - GitHub and contact links
   - Copyright information

## Technology Stack

- **Framework**: Next.js 14+ (App Router)
- **UI Library**: React 18
- **Styling**: Tailwind CSS v3+
- **Animation**: Framer Motion v10+
- **Icons**: React Icons
- **Font**: Inter (via next/font)

## Design System

- **Color Palette**: Dark background (#0f0f14), gradient accents (blue → purple → indigo)
- **Typography**: Inter/Geist font with proper hierarchy
- **Spacing**: Consistent use of Tailwind spacing scale
- **Shadows & Radius**: Glassmorphism effects with rounded-2xl corners
- **Animations**: Subtle fade-in, staggered cards, hover effects

## Installation

This project uses standard Node.js tooling:

```bash
npm install
npm run dev
```

## Development Scripts

- `npm run dev`: Start development server with hot reloading
- `npm run build:next`: Create a production build of the Next.js site
- `npm start:next`: Start the production server

This modern homepage delivers a premium, professional design that showcases the cutting-edge nature of the Physical AI Robotics platform while maintaining accessibility and performance standards.
