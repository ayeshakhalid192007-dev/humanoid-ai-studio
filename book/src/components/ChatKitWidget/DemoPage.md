# ChatKit Widget Demo

This page demonstrates the ChatKit-powered AI assistant integration with text selection features.

## Features

- **Text Selection**: Highlight text on the page to ask questions about it specifically
- **Contextual Assistance**: Get answers tailored to the current page content
- **Real-time Responses**: Streaming responses from our RAG-enabled AI assistant

## How to Use

1. **Select Text**: Highlight any text on this page
2. **Ask Questions**: Click the chat widget and ask questions about the selected text
3. **Get Answers**: Receive AI-generated responses based on the curriculum

## Example Usage

Try:
- Selecting text and asking about the concepts explained
- Asking for clarification on complex topics
- Requesting code examples for the concepts discussed
