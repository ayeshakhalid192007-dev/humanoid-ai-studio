# Welcome to Physical AI & Humanoid Robotics

Welcome to an immersive journey into the world of **Physical AI** and **Humanoid Robotics**! This interactive curriculum bridges artificial intelligence with physical embodiment, teaching you how to build autonomous humanoid robot systems.

## What You'll Learn

This comprehensive program covers four essential modules:

### 🤖 Module 1: ROS 2 Middleware
Learn the "nervous system" of robots - how to control and coordinate robot behavior using ROS 2 Humble, the industry-standard middleware for robotics.

**Key Topics**: Nodes, Topics, Services, URDF modeling, QoS policies

### 🎮 Module 2: Gazebo & Unity Simulation
Master physics-based simulation to safely test robot behaviors before deploying to hardware. Build digital twins with realistic physics, sensors, and environments.

**Key Topics**: Gazebo physics engines, sensor simulation, Unity integration, URDF spawning

### 👁️ Module 3: NVIDIA Isaac & Perception
Implement computer vision and autonomous navigation using NVIDIA Isaac ROS for GPU-accelerated VSLAM, and Nav2 for path planning.

**Key Topics**: Visual SLAM, Isaac ROS, Nav2 navigation, costmap planning, obstacle avoidance

### 🗣️ Module 4: Vision-Language-Action (VLA)
Integrate large language models with robotics to create voice-commanded autonomous systems that understand natural language and execute complex behaviors.

**Key Topics**: Speech-to-text, LLM integration, action planning, multi-layer safety validation

## Learning Approach

This curriculum follows a **Reasoning-First** pedagogy:

1. **Predict**: Before running code, predict what will happen
2. **Execute**: Run the code and observe actual behavior
3. **Reflect**: Compare prediction vs. reality and understand why

This active learning approach improves retention by 30-50% compared to passive tutorials.
